# Domain docs

## 탐색할 때 읽기

- 루트 `CONTEXT.md`를 읽는다.
- 작업에 관련된 현재 구조와 계약은 `docs/architecture.md`를 읽는다.
- `docs/adr/`에서 작업 영역에 관련된 결정을 읽는다.
- 파일이 없으면 조용히 진행한다. 도메인 모델링 작업에서 용어나 결정이 정리될 때 필요한 문서를 만든다.

## 구조

- `CONTEXT.md`: 저장소의 Electron Rx Bridge 도메인 용어
- `docs/adr/`: 아키텍처 결정

도메인 개념을 출력할 때 `CONTEXT.md`의 용어와 피해야 할 동의어를 따른다. ADR과 충돌하는 제안은 충돌한 ADR을 명시한다.
