# Issue tracker: Local Markdown

이슈와 작업 명세는 저장소의 `.scratch/` 아래 마크다운 파일로 관리한다.

## 규칙

- 작업 하나당 `.scratch/<feature-slug>/` 디렉터리를 둔다.
- 작업 명세는 `spec.md`에 기록한다.
- 개별 이슈는 `issues/NN-<slug>.md`로 만들고 `01`부터 번호를 붙인다.
- 이슈 상단에 `Status:`를 기록한다. 자유 형식 상태를 사용하며 triage 역할 라벨은 정의하지 않는다.
- 대화 기록은 파일 끝의 `## Comments`에 추가한다.

스킬이 이슈 트래커에 등록하라고 하면 해당 작업 디렉터리에 파일을 만든다. 기존 이슈를 가져오라고 하면 사용자가 준 경로 또는 번호에 해당하는 파일을 읽는다.
